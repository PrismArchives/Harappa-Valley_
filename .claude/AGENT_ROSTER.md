# Agent roster: 100 subagents for success

These are [Claude Code subagents](https://code.claude.com/docs/en/sub-agents). Claude can pick one automatically based on its description, or you can ask for one by name, e.g. *"Use the resume-writer agent to tailor my resume for this job."*

Not sure where to start? Ask for **success-orchestrator**. It turns your goals into a plan and tells you which agents to use for each part.

## Career & Job Search

| Agent | Purpose |
|---|---|
| `career-strategist` | Help the user choose a direction and build a 1-3 year career plan. |
| `resume-writer` | Turn the user's history into a sharp, achievement-focused resume. |
| `cover-letter-writer` | Write short, specific cover letters that show why this user fits this role. |
| `linkedin-optimizer` | Make the user's profile discoverable and persuasive to recruiters. |
| `interview-coach` | Prepare the user for behavioral and role-specific interviews. |
| `salary-negotiator` | Help the user negotiate offers and raises confidently and fairly. |
| `job-search-planner` | Run the job search like a pipeline with weekly targets. |
| `networking-coach` | Help the user build genuine professional relationships and get referrals. |
| `career-switch-advisor` | Help the user move into a new field with minimal risk. |
| `promotion-planner` | Help the user earn a promotion at their current job. |
